Composite weights

This page carries out the first step of the two-step approach of Treiblmaier, Bentler and Mair (2011): it divides a set of formative indicators into two or more composites and computes the weights that make those composites as highly correlated as possible, by canonical correlation analysis with two blocks and by generalized canonical correlation analysis with three or more. It then writes the Mplus input for the common factor that the composites define in the second step. It reads the raw data file of the analysis together with the TYPE = BASIC output that describes it; every number it computes with comes from those two files, and none of them can be typed in.

What to request from Mplus. ANALYSIS: TYPE = BASIC; together with OUTPUT: SAMPSTAT;. The output is read for the variable names, for USEVARIABLES, CATEGORICAL and the missing value codes, and the sample means it prints are compared with the means recomputed from the data file, which is how a data file read with the wrong number of columns or with an undeclared missing value code is detected.

What to do

  1. Write an Mplus input that reads the data file holding your formative indicators, name the columns in NAMES, and declare on USEVARIABLES the variables you want offered as indicators.
  2. Add this analysis command to it, exactly as it is written here: ANALYSIS: TYPE = BASIC;
  3. Add this output command to it, exactly as it is written here: OUTPUT: SAMPSTAT; — the sample means it prints are what the page compares its own reading of the data file against.
  4. Run that input in Mplus. The program writes a plain text file with the same name as the input and the extension .out, in the folder the input is in, and computes nothing beyond the descriptive statistics.
  5. Drop the raw data file on the first box below and the .out file on the second, in either order. Both are read inside your browser and neither leaves your computer.
  6. Read the paragraphs headed Output read, Data read and Means agree. The last one is the check that the data file and the output belong together: it compares the mean of every variable recomputed here with the mean Mplus printed.
  7. Choose how many composites to divide the indicators into, and assign each indicator to one of them, or leave it out, in the Composite column of the indicator table. Which indicators form which block is your decision, and the page offers only the variables it read from the output.
  8. Choose how the weights within each block are set: for maximal correlation between the composites, equal, or replicated as the first principal component of each block.
  9. Press Compute the weights. Read the canonical correlations, the weights, the standardized weights and the structure coefficients, and the checks under them.
  10. Copy the second-step Mplus input printed at the end, which builds the composites with DEFINE and fits the common factor on them, and run it.

The page refuses to compute anything until both files are loaded, because the data file alone gives no variable names, no missing value codes and no CATEGORICAL declaration, and the output alone gives no cases. It refuses a data file that produced no usable row, and it reports rather than hides a disagreement between the means it recomputed and the means Mplus printed, which is what a data file read with the wrong number of columns or with an undeclared missing value code looks like. Nothing on this page can be typed in: the sample size, the variable names, the values and the summary statistics all come from those two files, and the only decisions left to you are how many composites to form, which indicator goes into which of them, and how the weights within a block are set.

Methods and formulas

The two steps

A formative latent variable is written by Treiblmaier, Bentler and Mair (2011) as

F=b1V1+b2V2+…+bkVk+D

Here F is the formative latent variable, V1 to Vk are the observed indicators that define it, b1 to bk are their coefficients, and D is a disturbance uncorrelated with them.

The model is not identified: because F is unobserved the coefficients bi cannot be determined, and the disturbance has no rationale that would fix its variance. The proposal is to leave D aside and work with the determinate part, and to divide that part into two or more pieces:

P=b1V1+…+bkVk,P=P1+P2

Here P is the determinate part of F, that is F without its disturbance, and P1 and P2 are the two composites it is divided into.

In the second step those parts are treated as reflective indicators of a common factor F∗, which then approximates F as closely as the division allows. The common factor is identified, can be estimated, and can be placed in a larger structural model in the ordinary way.

Proposition 2 of the article states that the squared correlation between F∗ and F is maximized when the sum of the loadings β1+β2 is maximal and, for a given level of random error variance, the specific variances of the composites are minimal. The consequence the authors draw is that F∗ approximates F better as the composites are more highly correlated and the loadings larger, which is why a division that yields highly correlated parts is preferred even though formative measurement does not require the parts to correlate at all.

Step 1: the ways of dividing the determinate part

The article lists at least four ways of dividing P. Two of them fix the weights from outside the data, and this page does not compute them, because the numbers they need are in no file: the a priori split, in which the indicators are divided on theoretical grounds and the original coefficients bi are applied within each set, as in the odd and even sums P1=b1V1+b3V3+… and P2=b2V2+b4V4+…; and the split with original weights, in which each indicator is itself decomposed as Vi=Vi1+Vi2 and the same coefficient is applied to both halves. Both require the coefficients bi to be supplied, and a coefficient supplied by hand is a datum this page will not take. The article describes both, and a reader who has such coefficients can write the two DEFINE statements directly.

The two the page computes take their weights from the data:

  • Split with replicated weights. The weighting procedure is run separately in each half. The version computed here takes the first principal component of the correlation matrix of each block, which is the procedure the article names, and rescales it so that the composite has unit variance. Because the weights are estimated independently in the two halves they are free to differ, and the article observes that the parts may then be less highly correlated than under the original weights.
  • Split with weights for maximal correlation. The weights are chosen so that the two composites correlate as highly as they can. This is canonical correlation analysis (Hotelling, 1936), and it is the method the article uses in both of its examples.

Equal weights are offered as well, as the case of the replicated split in which every indicator counts once. The article adds that all of these methods can be used when P is to be divided into three or more parts, with canonical analysis of several sets of variables in the sense of Kettenring (1971) in place of ordinary canonical correlation analysis.

Maximally correlated composites: two blocks

Write S for the covariance matrix of the indicators, partitioned into Sxx, Syy and Sxy according to the division. The problem is to find weight vectors a and b that maximize

corr⁡(P1,P2)=a′Sxyb[(a′Sxxa)(b′Syyb)]

Here P1 and P2 are the two composites, a and b the weight vectors of the two blocks, Sxx and Syy the covariance matrices within each block, and Sxy the matrix of covariances between the two blocks.

Setting the derivatives to zero gives a pair of stationarity conditions:

Sxyb=ρSxxa,Syxa=ρSyyb

Here ρ is the correlation between the two composites and the matrices and vectors are those of the previous formula.

The solution comes from the singular value decomposition of a single matrix:

K=Sxx−1/2SxySyy−1/2=Udiag⁡(ρ1,ρ2,…)V′

Here K is the matrix whose singular values are the canonical correlations, Sxx−1/2 and Syy−1/2 are the symmetric inverse square roots of the two within-block matrices, U and V hold the left and right singular vectors, and ρ1 ≥ ρ2 ≥ … are the singular values.

The weights of the first pair of composites follow from the first singular vectors:

a=Sxx−1/2u1,b=Syy−1/2v1

Here u1 and v1 are the first columns of U and V, and a and b the weight vectors of the two blocks.

Because u1 and v1 have unit length these weights satisfy a′Sxxa=1 and b′Syyb=1: each composite has sample variance exactly one, computed with the n−1 divisor. That is the convention behind the raw canonical coefficients of SPSS MANOVA … /DISCRIM; the R function stats::cancor normalizes to a sum of squares of one instead, so its coefficients are those shown here divided by the square root of n−1. Weights obtained by any other method on this page are rescaled to unit composite variance in the same way, which changes no correlation and no standardized quantity and makes the raw weights of the different methods comparable.

The symmetric inverse square roots are built from the eigendecomposition of each block, computed by cyclic Jacobi rotations, and the singular value decomposition is a one-sided Jacobi sweep. Eigenvalues smaller than 10−10 times the largest are dropped, which turns the inverse square root into a Moore–Penrose pseudo-inverse. That happens exactly when a block is rank deficient — an indicator duplicated, a total entered together with its parts, an item recoded and kept alongside the original. The page then reports the rank of each block against the number of indicators in it, and truncates the solution to as many canonical dimensions as the smaller rank allows, because the directions that were dropped would return weight vectors of zero and a composite of zero variance is not a canonical variate. Inside a rank-deficient block the weights are not unique: the pseudo-inverse returns one solution out of infinitely many, all giving the same composite.

Maximally correlated composites: three or more blocks

With three or more blocks there is no single correlation to maximize, only a correlation matrix among the composites, and several criteria have been proposed for it. Kettenring (1971) collected them; all reduce to canonical correlation analysis when there are two blocks. Writing RP for the correlation matrix of the composites, each standardized to unit variance:

  • SUMCOR maximizes the sum of the correlations between all pairs of composites.
  • SSQCOR maximizes the sum of the squared correlations between all pairs, so a strong negative relation counts as much as a strong positive one.
  • MAXVAR maximizes the largest eigenvalue of RP, that is, the variance accounted for by the first principal component of the composites.
  • MINVAR minimizes the smallest eigenvalue of RP, which drives the composites towards a linearly dependent set.
  • GENVAR minimizes the determinant of RP, the generalized variance of the composites.

This page uses MAXVAR, in the formulation of Horst (1961) and Carroll (1968), because it is the criterion that matches the second step: what the second step extracts from the composites is a single common factor, and the largest eigenvalue of RP is exactly the variance one such dimension can account for. The computation stacks the blocks into one matrix whose blocks are

Mjk=Sjj−1/2SjkSkk−1/2

Here Mjk is the block of M in row j and column k, Sjj and Skk are the covariance matrices within blocks j and k, and Sjk is the matrix of covariances between them.

Its diagonal blocks are therefore identity matrices. Taking the eigenvector w belonging to the largest eigenvalue of M and normalizing each block of it to unit length gives the weights of block j:

aj=Sjj−1/2wj‖wj‖

Here aj is the weight vector of block j, wj is the part of the leading eigenvector belonging to that block, and ‖wj‖ is its length.

Writing cj=‖wj‖, the quadratic form w′Mw equals c′RPc with ‖c‖=1, so maximizing it over unit-length w is the same problem as maximizing the largest eigenvalue of RP: the largest eigenvalue of M and the largest eigenvalue of RP are the same number. The page reports the correlation matrix of the composites, that eigenvalue, and the proportion of the total variance of the composites it accounts for, which is the eigenvalue divided by the number of blocks. With two blocks M has the eigenvalues 1±ρj, its leading eigenvector is (u1,v1) up to a scale factor, and the procedure returns the canonical solution; the self-test checks that equality on the six-variable illustration and on two hundred random problems.

Raw weights, standardized weights and structure coefficients

Three quantities describe how an indicator enters a composite, and they answer different questions. The raw weight is the coefficient applied to the indicator in its own metric. It is the number that goes into the DEFINE statement, and it depends on the unit in which the indicator was measured: an item scored from 1 to 100 gets a weight about a hundred times smaller than the same item scored from 0 to 1. The standardized weight is the coefficient that would apply if the indicator and the composite were both standardized:

wi∗=wiσViσPj

Here w*i is the standardized weight of indicator i, wi its raw weight, σVi the standard deviation of the indicator, and σPj the standard deviation of the composite it belongs to.

It is comparable across indicators measured on different scales, and it is a partial coefficient: it says what the indicator contributes over and above the other indicators in the same block. The structure coefficient is the correlation between the indicator and its own composite:

r⁡(Vi,Pj)=(Sjjwj)iσViσPj

Here r(Vi, Pj) is the correlation between indicator i and composite j, (Sjjwj)i is the i-th element of the covariance matrix of the block multiplied by its weight vector, and the two standard deviations are those of the indicator and of the composite.

It is a simple correlation, so what the other indicators do does not affect it.

The article is explicit about which of the three to read: “In CCA, the canonical coefficients are typically not used; the correlations between the variables and the new canonical variates are interpreted instead. These are commonly referred to as loadings and can be interpreted as ordinary factor or component loadings” (Treiblmaier, Bentler, & Mair, 2011, p. 11). The reason is the usual one for regression coefficients: when the indicators are correlated, a weight can be small, or negative, merely because another indicator in the same block already carries that part of the variance, and the weight then says nothing about whether the indicator is related to the composite. The structure coefficient answers that question directly. A weight is a statement about a linear combination, not a measure of the importance of an indicator; the two coincide only when the indicators within a block are uncorrelated. The page prints all three and marks any block whose weights are of both signs, because such a composite is a contrast between groups of indicators rather than a weighted sum of them.

The sign of a whole canonical pair is arbitrary: replacing a by −a and b by −b leaves the correlation unchanged, and nothing in the data chooses between them. The page fixes the sign by making the sum of the structure coefficients of the first block positive, so that the composite runs in the same direction as the majority of its indicators. The relative signs within a block are not arbitrary and carry the meaning described above.

The published raw coefficients of an example are not always recoverable from a published matrix. The privacy example of the article reports raw canonical coefficients of .0197 and .0220 in the first block and .0292 and .0176 in the second, obtained from variables measured on a slider from 1 to 100. The canonical correlations and the structure coefficients are scale free: multiplying an indicator by a constant leaves them unchanged, so they can be reproduced from a correlation matrix. The raw coefficients are not: they carry the factor 1/σVi, and the standard deviations are not published. That example, and the six-variable illustration, are checked in the self-test of this page rather than offered as an input route, because a matrix copied out of an article is a number typed by hand.

How many dimensions, and how much is explained

With two blocks there are as many canonical correlations as there are indicators in the smaller block. Only the first pair of composites is used in the second step, but the others say whether the relation between the blocks is one-dimensional. Wilks's lambda for the dimensions from k+1 onwards, with k the number of canonical correlations already extracted, is

Λk=∏j>k(1−ρj2)

Here Λk is Wilks's lambda for the dimensions beyond the k-th, and ρj is the j-th canonical correlation, the product running over every dimension after the k-th.

Bartlett's (1941) large-sample test of the hypothesis that all the canonical correlations from that point on are zero in the population is

χ2=−[n−1−(p+q+1)2]lnΛk,df=(p−k)(q−k)

Here χ² is the test statistic, n the number of complete cases, p and q the numbers of indicators in the two blocks, k the number of canonical correlations already extracted, Λk Wilks's lambda just defined, and df the degrees of freedom the statistic is referred to.

The test at k=0 asks whether the two blocks are related at all; a test that is significant at k=1 as well says that a single pair of composites does not exhaust the relation between the blocks, which matters because the second step keeps only the first pair. The chi-square tail is computed from the upper incomplete gamma function evaluated by its continued fraction rather than as one minus the lower tail, which would lose every significant digit and return exactly zero for a probability below about 10−16.

The redundancy index of Stewart and Love (1968) is the proportion of the total variance of one set of indicators accounted for by the other set's canonical variate:

Rd⁡(X|Wj)=1p∑ir⁡(Vi,Wj)2=ρj21p∑ir⁡(Vi,Uj)2

Here Rd(X | Wj) is the redundancy of the first set given the j-th variate of the second, p is the number of indicators in the first set, Vi is one of them, Uj and Wj are the j-th canonical variates of the first and of the second set, and ρj is the j-th canonical correlation.

The two expressions are equal because the correlation of an indicator with the other set's variate is the canonical correlation times its correlation with its own, so the index is also the mean squared structure coefficient of the set multiplied by the squared canonical correlation. The page computes it the first way and checks it against the second; a difference above 10−6 would mean a numerical failure and is reported as one. Across two thousand randomly generated problems, including deliberately near-singular ones, the largest difference observed was 1.6 × 10−9. The index is asymmetric: the redundancy of the first set is generally not the redundancy of the second. A high canonical correlation with a low redundancy means that the composites are strongly related to each other and weakly related to the indicators they are built from, which is the situation in which the second-step factor represents very little of the material the formative construct was supposed to summarize.

Categorical indicators and optimal scaling

When the Mplus output declares indicators as CATEGORICAL, the numbers in the data file are category labels rather than measurements, and treating them as measurements assumes that the distance between category 1 and category 2 equals the distance between category 3 and category 4. The page replaces the labels by optimal quantifications: each category receives a numerical value, and those values are estimated jointly with the weights so as to maximize the fit between the composites, under a monotonicity constraint that keeps the quantifications in the order of the original categories when the level is ordinal and no constraint at all when it is nominal. This is the nonlinear canonical correlation analysis of Gifi (1990) as implemented in the OVERALS algorithm of van der Burg, de Leeuw and Verdegaal (1988): the loss function is the sum over blocks of the squared distance between a common object score matrix and each block's weighted sum of quantified variables; it is minimized by alternating least squares, one block at a time, with the monotone regression step carried out by the pool-adjacent-violators algorithm. Categories held by fewer than three cases, or by fewer than one per cent of the sample, are merged with the adjacent least frequent category before quantification, because a category held by two or three cases gets a quantification determined by those cases alone; the merges are reported. Because alternating least squares converges to a stationary point that depends on where it starts, the page restarts the algorithm from two deterministic configurations — the original category values, and the expected normal scores of the ranks — and then from random ones, and keeps the best solution, stopping once the same value of the loss function has been reached six times. When every indicator is numerical the quantification is a linear function of the original values, the alternating step has a closed-form solution, and the result is ordinary canonical correlation analysis; the self-test checks that equality.

Once the quantifications are fixed the quantified variables are treated as the observed variables: their covariance matrix is formed and every quantity on this page — weights, standardized weights, structure coefficients, canonical correlations, Wilks's lambda, redundancy — is computed from it in exactly the same way as for numerical indicators. The results show, for each categorical indicator, the weight applied to the quantified variable together with the quantification of every original category and the number of cases in it, so that the recoding can be checked; the generated syntax contains the same recoding as a sequence of IF statements, so the analysis is reproducible from the syntax alone. When the monotone fit assigns the same value to neighbouring categories the page says so, because the indicator is then being used as a coarser variable than it was measured.

Step 2: the factor on the composites

The composites are entered as reflective indicators of a common factor:

P1=β1F∗+E1,P2=β2F∗+E2

Here P1 and P2 are the two composites, F* is the common factor of the second step, β1 and β2 are its loadings on them, and E1 and E2 are two residuals uncorrelated with each other.

With two composites this model is not identified as it stands: two loadings, two residual variances and the factor variance are five parameters against the three distinct elements of the covariance matrix of P₁ and P₂. Fixing the factor variance at one and constraining the two loadings to be equal leaves three free parameters against three moments, which is a just-identified model; the article applies exactly this restriction, and justifies it both by the standard cautions for two-indicator factors and by the composites being built from equivalent sets of indicators. Constraining the two residual variances to be equal as well leaves two free parameters and one degree of freedom, so the equivalence of the two composites becomes a testable restriction rather than an assumption. The generated syntax imposes both constraints and says in comments what each of them does. When the composites are standardized to unit variance, as the weights on this page make them, the standardized loading is the square root of the correlation between them: the article's .746 for the a priori split of the six-variable illustration and .894 for the canonical split, and .681 for the privacy example.

With three or more composites the loadings need no equality constraint: the factor variance is fixed at one, and the loadings and the residual variances are all free. With three composites the model is again just identified; with four or more it has degrees of freedom. The generated syntax is read back by the page and checked before it is shown, and the checklist under it reports what was verified: that every variable used on the right-hand side of a DEFINE statement is either declared in NAMES or created earlier in DEFINE, that every composite appears in USEVARIABLES, that no intermediate quantified variable has been left there, that no name exceeds the eight characters Mplus allows and no line the ninety it reads, and that the coefficients read back out of the DEFINE statements match the weights in the table. The check on the intermediate variables matters because a variable created in DEFINE and listed in USEVARIABLES enters the model as an observed variable: the quantified variables would then be analyzed alongside the composites, and Mplus would return a fit that has nothing to do with the intended model. Only the composites belong in USEVARIABLES.

Choosing the division from the data

The exploratory search examines the ways of dividing the selected indicators into two blocks and reports the one whose first canonical correlation is highest. A division is represented as an integer with one bit per indicator, the first indicator held in the first block so that a division and its mirror image are not counted twice; the number of distinct divisions of k indicators is therefore 2k−1 − 1, which is 15 for five indicators. Bit tests and the population count are done by division rather than by the bitwise operators of the language: those coerce their operands to signed 32-bit integers, so 1 << 32 wraps round to 1 and a population count written with >>= never terminates once bit 31 is set. Division is exact up to 253, and the search is limited to 50 indicators, which is well inside that. The self-test checks the population count at and above 32 bits. The search runs in chunks of a few tens of milliseconds with the page yielding between them, so the tab stays responsive and the progress bar advances; the enumeration is exhaustive up to 200000 divisions, which is 18 indicators, and switches to hill climbing from random starting divisions beyond that, in which case the division found is not certainly the best one and the page says so.

Two things have to be held together here. The article does say that, for its purposes, the best division is the one that yields highly correlated parts, and Proposition 2 gives the reason. But the article obtains a high correlation by choosing the weights optimally within a division fixed on substantive grounds, and choosing the division itself by the same criterion on the same data is a further step it does not take. The canonical correlation is already a maximum over all weight vectors, so it is biased upwards in any sample; maximizing it over the divisions as well adds a second layer of capitalization on chance, and the value that comes out is not an estimate of a population quantity. The search is useful for seeing how much the answer depends on the division and whether one indicator is consistently isolated, and its result is a hypothesis to be checked on other data rather than the division to report. A division defensible on content grounds, with the weights then chosen for maximal correlation, is what the article proposes.

Missing data

Cases are deleted listwise: a case is used only if it has a valid value on every indicator assigned to a composite, and indicators left out of the analysis do not cause a case to be dropped. The page reports the number of complete cases used, the number dropped, and the number of cases available on each indicator separately, so that a single indicator responsible for most of the loss can be identified. Values matching a missing value code declared in the Mplus output, and the codes . and *, are treated as missing; the numeric codes are compared as numbers, so that −99, −99.0 and −99.000 are recognized as the same code. No imputation and no full-information estimation is available here, because the first step is a computation on a covariance matrix rather than a model fitted by maximum likelihood. When the proportion of dropped cases is large, the covariance matrix is that of the complete cases and generalizes to the rest of the sample only under an assumption this page cannot check.

What this page does not do

The disturbance D of the formative construct is not estimated, and cannot be: proceeding without it is the point of the two-step approach, so the correlation between F* and the intended F is unknown in any application, as the article states. Nothing here decides whether a construct should be measured formatively at all; that argument is conducted in Bollen and Lennox (1991), Diamantopoulos and Winklhofer (2001) and Bollen (2002), and it has to be settled before these computations are of any use. The weights are sample quantities with no standard errors attached, and the canonical correlation is a maximum over weight vectors, so it is biased upwards in small samples; the page reports the ratio of complete cases to indicators and warns below five cases per indicator. The exploratory search works on the covariance matrix of the raw values even when indicators are categorical, because a quantification would have to be recomputed for every division. The page reads a raw data file, so the covariance matrix it works from is on the metric of the variables themselves and the DEFINE statements it writes apply to them unchanged.

Self-test

Adding ?selftest=1 to the address of this page runs the numerical checks in the browser and prints the result at the top of the page and in the console. They cover the two published benchmarks of Treiblmaier, Bentler and Mair (2011), which appear here and nowhere else on the page, because a matrix copied out of an article is a number typed by hand: the six-variable illustration end to end — the a priori weights .5, .6 and .7 giving composite variances of 1.1, a covariance of .612, a correlation of .5564 and an equal standardized loading of .746, and the canonical correlation of .8 giving .894 — and the canonical correlations, the structure coefficients and the loading of .681 of the privacy example; the agreement of the generalized routine with canonical correlation analysis when there are two blocks; Wilks's lambda, Bartlett's statistic and its degrees of freedom against their definitions; the chi-square tail below the point where one minus the lower tail returns zero; the pseudo-inverse path and the truncation of dimensions on a rank-deficient block; the enumeration of the divisions of five indicators and the population count at 231, 232, 240 and 249; the redundancy index computed both ways and agreeing; the free-format data parser, the matrix parser, the variable-range expander and the Mplus input parser on embedded samples; the pool-adjacent-violators algorithm against monotone fits worked out by hand; optimal scaling with numerical levels reproducing canonical correlation analysis and an ordinal quantification coming out monotone; the generated syntax for two and for three composites, read back and checked; and a randomized run of 220 problems asserting that every composite has unit variance, that the correlation between the composites equals the first canonical correlation, that the stationarity conditions Sxyb = ρSxxa and Syxa = ρSyyb hold, that the canonical correlations lie between zero and one and do not increase, and that they agree with an independent computation through the eigenvalues of Sxx−1SxySyy−1Syx obtained by a Gauss–Jordan inverse and unshifted QR iteration, which share no code with the routines they check.
