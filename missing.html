Missing Data

This page reads what Mplus prints about the missing data of an analysis and turns it into what has to be reported: how much is missing on each variable, how the missing values are patterned, how many cases each pair of variables shares, whether the attrition of a longitudinal design is monotone, and how much information the missing data cost each parameter: read from the output for an analysis of imputed data, together with the efficiency the number of imputations achieves, and obtained from a second run of the model for an analysis fitted by full information maximum likelihood.

What to request from Mplus. OUTPUT: PATTERNS SAMPSTAT; — PATTERNS prints the missing data patterns and their frequencies, and Mplus prints the covariance coverage of a run with missing data on its own. For the fraction of missing information of an analysis of imputed data, DATA IMPUTATION: or TYPE = IMPUTATION, whose results table carries the column Mplus heads Rate of Missing. For the fraction of missing information of an analysis fitted by full information maximum likelihood, add RESIDUAL to the OUTPUT command as well: the page then writes the second run that the procedure of Savalei and Rhemtulla (2012) needs. A warning printed by Mplus is reported and does not remove a result the file supports; what removes a result is a quantity that is missing or inadmissible.

What to do

  1. Add PATTERNS to the OUTPUT command of the analysis, and RESIDUAL as well if the analysis is fitted by full information maximum likelihood; then run it.
  2. Drop the .out file on the box below.
  3. If the variables are the waves of a longitudinal design, tick the box under the file: the page then reads the order in which they are printed as the order in time and reports the attrition.
  4. Read the tables. What is missing from the file is named rather than assumed.
  5. For a FIML analysis, save the data file and the input the page writes at the end, run that input, and drop its output on the second box: the fraction of missing information of every parameter follows.

What the file reports

The fraction of missing information of a FIML analysis

An analysis of imputed data carries the rate of missing in its results table, and the section above reports it. An analysis fitted by full information maximum likelihood carries no such column, and the fraction of missing information of each parameter is then obtained from two runs of the same model rather than one: Savalei and Rhemtulla (2012) define it as one minus the ratio of the squared standard error the estimate would have carried with complete data to the squared standard error it carries here, and obtain the first of the two by refitting the model to the means and covariances the first run implies. The page writes that second run from the file already loaded, and computes the fractions once its output is loaded in turn.

The second run appears here once an output fitted by full information maximum likelihood has been read above.

Mplus reads a covariance matrix given to it as scaled by n−1. The correction matters with a small sample and is the one the authors apply.

Methods and formulas

What the page reads

Three sections of the output, and nothing else. SUMMARY OF MISSING DATA PATTERNS gives the patterns themselves, printed as a column of crosses and dots for each pattern, and the frequency of each; the covariance coverage table gives, for every pair of variables, the proportion of cases observed on both, and on its diagonal the proportion observed on each variable alone; and the results table of an analysis of imputed data gives the column Mplus heads Rate of Missing. When a section is absent the page says which one and what would have printed it.

Coverage

The coverage of a pair of variables is the proportion of cases with a value on both. It is what decides whether a covariance can be estimated at all: a pair observed together in a handful of cases carries a covariance whose standard error is enormous, and Mplus refuses to proceed when any coverage falls below the value set in COVERAGE =, which is .10 by default. The page lists every pair below the value chosen above, and reports the smallest coverage in the matrix, which is the number to give in a paper alongside the sample size.

Patterns, monotonicity and attrition

A pattern is a distinct arrangement of observed and missing values. The number of patterns, the frequency of the complete pattern and the frequency of the largest incomplete ones describe the shape of the missingness in a way that a single percentage cannot. In a longitudinal design the patterns also say what kind of attrition there is. Missingness is monotone when a case that is missing at one wave is missing at every later wave, which is dropout; it is intermittent when a case comes back after a wave it missed. The distinction matters because the two are not handled alike: monotone missingness admits methods that non-monotone missingness does not, and intermittent missingness is often informative about the reason for the absence. The page classifies each pattern by reading the printed order of the variables as the order in time, which is why that reading has to be confirmed with the box above.

The fraction of missing information

With multiple imputation the uncertainty of a parameter has two parts: the variance of its estimate within each imputed data set, averaged over imputations, and the variance of the estimate across imputations. The second is the part the missing data are responsible for. Mplus prints their ratio in the column Rate of Missing:

FMI=BB+W

Here B is the variance of the point estimate across imputations and W the variance of the point estimate within an imputed data set, averaged over the imputations (Muthén, n.d.). Rubin's (1987) fraction of missing information carries in addition a correction for the number of imputations and for the degrees of freedom, γ=r+2/(ν+3)r+1 with r=(1+1/m)B/W; the two agree closely and the page reports the value the file carries rather than recomputing it, because B and W are not printed separately.

The efficiency of an estimate based on m imputations, relative to an infinite number of them, is

RE=(1+FMIm)−1

Here m is the number of imputations and FMI the fraction of missing information of that parameter (Rubin, 1987). The page reports it for the number of imputations set above, and the number of imputations that would be needed to reach an efficiency of 99 percent for the parameter with the largest fraction, which is the one that governs the choice.

Under full information maximum likelihood no imputations are drawn and Mplus prints no such column, but the quantity is defined there as well. Savalei and Rhemtulla (2012, Equation 4) write it for the jth parameter as

λj=1−SEj,C2SEj,O2

Here SEj,O is the standard error the estimate carries on the observed data and SEj,C the one it would have carried had the data been complete. The second is not printed anywhere, and the authors obtain it from a second run rather than from a formula: the model is fitted again to the means and covariances the first run implies, treated as complete data on the same number of cases. Their four steps are the ones this page follows. The first run is the analysis itself, fitted with observed information, which is what Mplus uses by default when FIML is requested and what gives consistent standard errors under MAR (Kenward & Molenberghs, 1998); from it come SEj,O, the implied means and covariances that OUTPUT: RESIDUAL; prints, and the number of observations. The page writes the second run from those, copying the MODEL command out of the input Mplus echoes at the head of the output; the implied covariances are scaled by n/(n−1), as the authors do, because Mplus reads a covariance matrix given to it as scaled by n−1. From the output of that run come the SEj,C, matched to the first by the name of the parameter and the heading it is printed under.

A standard error is printed to three decimals, which on a value near .05 would leave the fraction good to about a hundredth. The same row prints the estimate and its ratio to the standard error, to three decimals as well, and their quotient recovers the standard error to several more digits whenever the estimate is the larger of the two; the page uses whichever of the two carries the smaller relative error, taking half a unit in the last printed place as the error of each, and ignores the quotient when it disagrees with the printed value by more than the printing allows.

Beside each fraction the page reports the three readings the authors give (2012, p. 488): the effective sample size nj*=n(1−λj), which is the number of complete cases that would have estimated the parameter as precisely; the sample size n/(1−λj) that would have been needed to reach with these data the precision complete data would have given; and the width inflation factor 1/1−λj, the factor by which the confidence interval is wider than it would have been.

The procedure holds for a single-level model of continuous variables estimated by ML, and the page refuses the rest rather than printing a number that does not mean what it says: the standard errors of MLR and of the weighted least squares estimators cannot be reproduced from a covariance matrix, and a two-level, complex survey or mixture model is not fitted from moments in this form. Chen and Savalei (2021) compare three ways of computing the same quantity from the information matrices directly, recommending the third; those are implemented in lavaan, which reports the fraction with parameterEstimates(fit, fmi = TRUE).

What the page never does is put the proportion of missing values in the place of the fraction of missing information, which is a different quantity: a variable with much missing data costs little information when the variables observed alongside it predict it well, and a variable with little missing data costs a great deal when nothing else in the model is related to it.

Self-test

Adding ?selftest=1 to the address of this page runs its numerical checks in the browser and prints the outcome at the top. They cover the reading of the pattern table, of the frequencies and of the coverage matrix from synthetic outputs written for the purpose, the classification of monotone and intermittent patterns, the relative efficiency against its definition, the number of imputations that reaches a given efficiency, the reading of the implied moments and of the echoed input, the writing of the complete data run, the recovery of a standard error from the ratio printed beside it, the fractions of missing information against the four values of Table 1 of Savalei and Rhemtulla (2012), the three readings of their page 488, and the cases the page has to refuse.
