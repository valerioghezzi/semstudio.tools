Privacy

This site consists of static pages. It sets no cookies, uses no analytics or tracking scripts, loads no resources from third parties, and contains no forms that send information anywhere.

The calculators run entirely inside your browser. Files you open with them (Mplus output files, data files) are read by your browser on your computer and are never transmitted. Closing the page discards them.

The pages are served by GitHub Pages. Like any web server, GitHub may record the IP address and the request of each visit in technical logs, for the time and purposes described in GitHub's privacy statement. The author of this site has no access to those logs and receives no information about visitors.

Questions about this notice can be sent to valerio.ghezzi@uniroma1.it.
