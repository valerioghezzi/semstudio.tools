Chi-square difference test

Reads two Mplus output files, checks the conditions that a nesting relation requires, and computes the difference test that the estimator of those two runs allows: the classical difference for ML, MLF, GLS and WLS, the Satorra-Bentler scaled difference for MLR, MLM and WLSM, and the DIFFTEST result for MLMV, WLSMV and ULSMV.

What to request from Mplus. Nothing beyond the standard output: the page reads MODEL FIT INFORMATION, which Mplus always prints. With MLMV, WLSMV or ULSMV add SAVEDATA: DIFFTEST = file.dat; to the less restricted run and ANALYSIS: DIFFTEST = file.dat; to the restricted one, because for those estimators the difference of the two printed statistics is not chi-square distributed.

Load the two outputs

Drop one Mplus output file in each zone, or press a zone to choose a file. The page identifies the restricted model on its own: the one with more degrees of freedom is treated as H0. Files are read by your browser and are not transmitted anywhere.

Third output, for the strictly positive scaled test (Satorra & Bentler, 2010)

This file is needed only when the standard scaled difference test cannot be computed, that is when the difference scaling correction cd is zero or negative, or when the test statistic comes out negative. It is a run of the restricted model in which every parameter starts at the unrestricted solution and the estimation is stopped before the first update (ANALYSIS: ITERATIONS = 0;). The page takes from it only the scaling correction factor of the chi-square, written c10.

Methods and formulas

Nested models

A model M0 is nested in a model M1 when M0 follows from M1 by imposing restrictions on free parameters, such as fixing a parameter at a value or forcing two parameters to be equal, with the same data, the same observed variables and the same estimator. M0 therefore has fewer free parameters and more degrees of freedom than M1. Output files carry the necessary conditions, not the proof: they show whether the two runs share the sample, the dependent variables and the estimator, whether the difference in degrees of freedom matches the difference in free parameters, and whether the fit statistics fall in the expected order. Whether the restricted model is genuinely a restriction of the free one follows from the specification of the two models, which the page reports side by side.

Classical difference test: ML, MLF, GLS, WLS

These estimators produce a statistic that is asymptotically chi-square distributed, and the difference of two such statistics is again chi-square distributed:

T  = chi2_0 - chi2_1
df = df_0 - df_1

MLF differs from ML in the standard errors, which use the first-order derivative information matrix; the chi-square test of model fit it prints is the ML statistic, so the classical difference applies to MLF unchanged.

Scaled difference test: MLR, MLM, WLSM

These estimators print a statistic that has already been divided by a scaling correction factor c, so the scaled difference test of Satorra and Bentler (2001) multiplies the printed values back before differencing them:

cd = (df_0 * c_0 - df_1 * c_1) / (df_0 - df_1)
T  = (chi2_0 * c_0 - chi2_1 * c_1) / cd

T is referred to a chi-square distribution with df_0 - df_1 degrees of freedom. The factors c_0 and c_1 are the values Mplus prints as Scaling Correction Factor under the chi-square of each model. Subtracting the two printed statistics without the correction does not give a chi-square statistic.

Log-likelihood version of the scaled test

When both outputs report an H0 log-likelihood and its scaling correction factor, the same test can be computed from the log-likelihoods, with p the number of free parameters and c the H0 correction factor:

cd = (p_0 * c_0 - p_1 * c_1) / (p_0 - p_1)
T  = -2 * (L_0 - L_1) / cd
df = p_1 - p_0

The page computes both versions when it can and reports them together. They answer the same question and should agree; a disagreement is flagged, because with the same data and the same nesting it points to an inconsistency between the two files rather than to a substantive result.

Strictly positive scaled test

The scaled difference test can produce a non-positive cd or a negative T, and neither outcome is a non-significant test: the test is simply not computable in that form. Satorra and Bentler (2010) give a version that is strictly positive by construction, and Bryant and Satorra (2012) set out the steps. It needs one additional Mplus run of the restricted model in which the unrestricted solution supplies the starting values and the estimation is stopped before the first update, so that Mplus evaluates the restricted model at the unrestricted estimates and prints the scaling correction factor of that evaluation, written c10. With that factor the correction becomes

cd* = (df_0 * c10 - df_1 * c_1) / (df_0 - df_1)
T   = (chi2_0 * c_0 - chi2_1 * c_1) / cd*

Load that output in the third zone above and the page computes T with cd* in place of cd.

Mean- and variance-adjusted estimators: MLMV, WLSMV, ULSMV

These estimators adjust both the mean and the variance of the test statistic, and the degrees of freedom Mplus prints for them are not the difference between the number of moments and the number of free parameters. The difference of two such statistics is not chi-square distributed under any rescaling, so the test has to be produced by Mplus itself with the DIFFTEST option (Asparouhov & Muthén, 2006), in two runs:

! Step 1: the less restricted model (H1)
SAVEDATA:   DIFFTEST = deriv.dat;

! Step 2: the restricted model (H0), same data and variables
ANALYSIS:   DIFFTEST = deriv.dat;

The second output then contains a block headed Chi-Square Test for Difference Testing with a value, its degrees of freedom and a p-value. When the restricted model you load contains that block, the page reads it and reports it; when it does not, the page prints the procedure and computes nothing.

Files this page will not read

Four kinds of file are refused with a message rather than read. A file written with the abbreviated invariance syntax (MODEL = CONFIGURAL METRIC SCALAR;) holds several models, each with its own fit statistics, and no single chi-square belongs to it; the page reads none of them and names the models it found. A file that stops before the sections that follow the fit statistics comes from a run that was interrupted, and the numbers in it may belong to a model that was never finished. A file with none of the headings Mplus always writes is not an output at all. And an empty file is reported as empty. In each case the page says which file and why, and computes nothing: a difference test built on numbers read out of one of these would look like a result.

Estimators without a chi-square difference test

ULS prints no chi-square test of model fit, so there is nothing to difference; the mean- and variance-adjusted ULSMV with DIFFTEST is the usual route to a test. BAYES estimates the model by MCMC and prints no chi-square: model comparison there rests on the posterior predictive p-value for absolute fit and on the DIC for relative fit.

Differences in fit indices

The chi-square difference test answers whether the restrictions are compatible with sampling error, and with a large sample a difference of no practical size can reach significance. For that reason the change in the approximate fit indices is usually reported next to the test. The page computes each difference as the value of the restricted model minus the value of the free model, for CFI, TLI, RMSEA, SRMR, AIC, BIC and the sample-size adjusted BIC. Cutoffs proposed in the literature:

  • Cheung and Rensvold (2002): a change in CFI of at least -.010, that is a drop no larger than .010, supports the constrained model.
  • Chen (2007): a change in CFI of -.010 together with a change in RMSEA of .015 and a change in SRMR of .030 for constraints on loadings, or .010 for constraints on intercepts, thresholds and residuals. For samples of 300 or fewer, or with unequal group sizes, the stricter values are -.005 for CFI, .010 for RMSEA and .025 for SRMR with loadings, .005 with intercepts and residuals.
  • Rutkowski and Svetina (2014), for comparisons across many groups: a change in CFI of -.020 with a change in RMSEA of .030 at the metric step, and -.010 with .010 at the scalar step.
  • Raftery (1995), for BIC differences between two models fitted to the same data: 0 to 2 weak, 2 to 6 positive, 6 to 10 strong and above 10 very strong evidence for the model with the lower value.
  • Burnham and Anderson (2004), for AIC differences: a difference up to about 2 leaves both models substantially supported, 4 to 7 gives the higher model considerably less support, and above about 10 essentially none.

A change exactly equal to a cutoff is counted here as within it. These values come from simulation studies run under specific conditions of sample size, number of groups, number of indicators and type of misspecification, and they do not replace the evaluation of the model: a change within a cutoff is not evidence that the constraints hold, and a change beyond it is not by itself grounds for rejecting them. When the checks find something that a nesting relation excludes, the two sets of fit values are still shown but the cutoffs are not applied, because they were derived for nested comparisons. The information criteria are compared only when the two runs used the same number of observations, since they are on the scale of the log-likelihood of the sample.

Self-test

Adding ?selftest=1 to the address of this page runs its numerical checks in the browser and prints the outcome and the number of checks at the top. They cover the upper tail of the chi-square distribution against eighty published quantiles from 1 to 100 degrees of freedom and against a series and continued-fraction implementation written separately for the purpose; the classical difference, the Satorra-Bentler scaled difference, its strictly positive form and the log-likelihood version, each over more than a thousand randomly drawn problems, with the cases that cannot be computed counted separately to confirm that they are refused rather than reported; the differences in the fit indices; both sides of every cutoff the page can show, including a change exactly equal to it; the bands of the Raftery and of the Burnham and Anderson scales at their boundaries; the parser on synthetic outputs for every estimator, on a file written with the abbreviated invariance syntax, on a truncated file, on an empty file, on a file that is not an output, on runs that did not converge and on runs with errors and with warnings; three groups of unequal size; values that cannot be right typed by hand; and the decoding of Windows-1252, UTF-8 with and without a byte-order mark, and UTF-16 in both byte orders.
