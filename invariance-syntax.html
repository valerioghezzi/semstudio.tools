Invariance Syntax Builder

Describe the model you mean to fit — its factors and their items, its groups, its estimator — and this page writes the Mplus input for a sequence of identified multiple-group confirmatory factor models. For continuous indicators it writes the configural, metric, scalar and strict models and the optional structural steps; for ordered categorical indicators it writes the sequence of Wu and Estabrook (2016) as applied by Svetina, Rutkowski and Rutkowski (2020), in which each level is identified on its own rather than by adding constraints to an identified baseline. Nothing is estimated here: what is written is input, to be run in Mplus on your data.

What every input written here asks for. Each one ends with OUTPUT: TECH1 TECH4 STDYX;. TECH1 prints the parameter specification group by group, which is the direct way to check that each equality constraint was placed on the intended parameter; TECH4 prints the estimated factor means, variances and covariances, which are the quantities the later levels license you to compare; STDYX gives the standardized loadings.

What to do

  1. Say whether the items are continuous or ordered categorical, in the first box under The model. That choice decides which of the two sequences is written, which estimators are offered, which levels can be ticked, and whether the number of response categories and the parameterization are asked for at all.
  2. Write the factor definitions, one factor to a line, exactly as they would be written in Mplus: F1 BY x1 x2 x3; The hyphen range notation is read, so F1 BY x1-x4; is the same definition. Each item may belong to one factor only.
  3. Give the number of groups, the name of the grouping variable, and the code and the name of each group, written as 1 = male, 2 = female. The code is the value the grouping variable takes in the data file; the name is what Mplus calls that group, so it obeys the naming rules of a variable.
  4. Choose the estimator. Which difference test the sequence can use follows from it: with MLMV, WLSMV and ULSMV the page pairs a SAVEDATA: DIFFTEST = file to an ANALYSIS: DIFFTEST = file between consecutive levels, and with the others it does not.
  5. With ordered categorical items, give the number of response categories: one number for every item, and, for items that differ from it, a number of their own in the table under Give particular items a different number of categories. An item with fewer than four categories contributes nothing to the test of threshold invariance, which is why the number matters here.
  6. Tick the levels of the sequence to write, choose how the factors are identified, and, with ordered categorical items, choose the parameterization. These are the choices that are not part of the description of the model.
  7. Press Write the inputs. Each input appears with the checks it passed under it. Copy one with the button beside its heading, or press Download every input as a separate .inp file to save them all, then run them in Mplus in the order they are written.

The page refuses a description it cannot write an identified sequence for, and says which part of the description is at fault: a line that is not a factor definition, an item listed on two factors, a name longer than the eight characters Mplus allows or one of the words the language reserves, a group name used twice, fewer than two groups, or a number of categories below two or above twelve.

The model

Write the sequence for these indicators
One factor to a line, written as it would be written in Mplus: F1 BY x1 x2 x3 x4; The hyphen range notation is read, so F1 BY x1-x4; is the same definition. Semicolons may be left out. Names may be up to eight characters, must begin with a letter and may contain letters, digits and underscores. Each item may belong to one factor only.
Separated by commas, as code = name. The names go into the GROUPING statement and head the MODEL blocks, so they follow the same naming rules as variables. The first group named is the reference group. A group left out of the list takes its position as its code and G followed by that position as its name.
Under the fixed-factor method the variance of each factor is fixed at one and its mean at zero in every group at the configural level, and in the first group only once the loadings, or the intercepts, are held equal. Under the marker method the loading of the first item of each factor is fixed at one in every group, the factor variances are free everywhere, and the factor means are fixed at zero until the intercepts are held equal.
Maximum likelihood estimators for continuous indicators, weighted or unweighted least squares estimators for ordered categorical ones; the words after each name say how its chi-square is adjusted. The menu changes with the choice of indicators and starts from its first entry. The difference test follows from the estimator and is named under the inputs.
Invariance of the residual variances of the latent responses can be imposed only under THETA, where those variances are parameters. Under DELTA the corresponding step fixes every scale factor to one in every group, which holds the total variance of each latent response equal across groups instead; the two coincide only when the factor variances are also equal across groups, so this page writes that step only under THETA.

The inputs

! What this page cannot do. The syntax written below is a starting point to be read and checked against your data and your model before it is run. The page cannot verify that a model is identified for every structure that can be described to it: cross-loadings, correlated residuals, an item belonging to more than one factor, factors with one or two indicators and groups in which the model is empirically underidentified all change the identification argument, and the conditions used here are those given for a clustered pattern of non-negative loadings with each item on one factor.

Why the ordered categorical sequence differs from the continuous one

With continuous indicators the observed variable has a metric of its own. Its mean and its variance are estimated in every group, so an intercept and a residual variance can be estimated in every group as well, and the sequence configural, metric, scalar, strict (Millsap, 2011) adds one type of constraint at a time to a model that is already identified.

With ordered categories nothing is observed but the proportion of respondents in each category and the association between items. The model puts a normally distributed latent response variable behind each item and cuts it at thresholds, and that latent response has no metric of its own: its location and its scale are conventions. Wu and Estabrook (2016) write the transformation that changes those conventions without changing the probability of any response pattern. It has four parts in each group: a shift and a rescaling for every latent response, and a shift and a rescaling for every factor, so 2(p+m) constraints per group are needed to identify a model with p items and m factors.

The consequence is that the identification condition of a baseline model is not neutral with respect to the invariance tests that follow it. Once loadings are held equal across groups, a condition such as fixing the variance of every latent response to one in every group stops being a free choice of metric and becomes a restriction, and the same invariance hypothesis tested from two differently identified baselines gives two different chi-squares. Wu and Estabrook show a two-group example in which loading invariance is rejected under two identification conditions and retained under a third, with the same data and the same true parameters. Their answer is to identify each level of invariance separately, which is what this page writes.

Three consequences follow for the sequence itself.

  • Invariance of loadings alone, of intercepts alone, and of residual variances alone cannot be tested. A model with only one of these constrained is statistically equivalent to the configural model, so the difference test has no degrees of freedom to spend. Threshold invariance has to be established first (Wu & Estabrook, 2016, Proposition 5 and Section 6).
  • How much of threshold invariance can be tested depends on the number of categories. A shift and a rescaling of one latent response can always be chosen to make one threshold match, and can be chosen to make two thresholds match, but not three. An item with C categories therefore contributes (C−3)(G−1) degrees of freedom to the test of threshold invariance across G groups: none at all for a binary or three-category item, one per extra group for a four-category item.
  • Binary items are a separate case. With one threshold per item, threshold invariance and threshold-and-loading invariance are both statistically equivalent to the configural model (Wu & Estabrook, 2016, Propositions 3 and 6), and the model that holds thresholds invariant while freeing the intercepts and the scales of the other groups is not even identified. When any item is binary this page drops those two levels and goes from the configural model to the model with invariant thresholds, loadings and intercepts. The intercepts are not the only class that can carry that step: holding the residual variances of the latent responses equal instead, with the intercepts left free, imposes the same number of restrictions on the configural model, and applied accounts of the binary sequence often take that route. The two models are each a restriction of the configural one and neither is a restriction of the other, so a difference test between them is not defined; this page writes the first of the two and names it in the heading of the input.

The two articles differ in how far they take the sequence and in what they call the levels. Wu and Estabrook (2016) name each model by the parameters it holds invariant and set out the whole hierarchy of sixteen models, of which ten are statistically distinct for polytomous items and five for binary items. Svetina, Rutkowski and Rutkowski (2020) follow the same identification conditions but write out three models only, which they name after the propositions they come from: the baseline model, Proposition 4 for threshold invariance and Proposition 7 for threshold and loading invariance. They also point out that the resulting order — thresholds first, then loadings — differs from the order in which applied work usually proceeds, where loadings are tested before thresholds and intercepts. One detail in their tutorial is a slip: the text and the annotation of the Proposition 7 input say that the item intercept is fixed at one in the first group and give [y1-y4@1];, while Condition 19 of Wu and Estabrook, which that step implements, sets those intercepts to zero. This page writes @0.
